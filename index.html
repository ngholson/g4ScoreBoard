OBS Studio Integration Links

Use these direct URLs in OBS Studio to add the scoreboard to your stream and dock the control panel into the OBS interface.

1. Pro Broadcast Bar (Bottom Center)

Clean broadcast bar with solid score blocks, crisp player names, race to X, extensions, and integrated shot clock.

2. Pro Broadcast Scorebug (Top-Left)

Broadcast scoreboard docked neatly in the top-left corner of the stream canvas.

3. Pro Compact Bar

Ultra-clean compact edition designed for minimal stream canvas footprint.

4. Shot Clock Dedicated Display

Digital shot clock display for a secondary player monitor or dedicated shot clock window.

5. Control Panel (OBS Custom Dock)

Operator dock for adjusting player names, colors, scores, extensions, timers, and logos.

Quick OBS Studio Setup Guide

  1. In OBS Studio, go to Docks → Custom Browser Docks...
  2. Enter Dock Name: g4ScoreBoard and paste the Control Panel URL into the URL field, then click Apply.
  3. In your streaming scene, add a new Browser Source.
  4. Set URL to the Scoreboard Overlay URL.
  5. Set Width to 1920 and Height to 1080, then click OK.
